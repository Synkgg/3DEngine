# Engine documentation website

Static, dependency-free documentation for the current engine.

Open `Docs/index.html` in a browser, or serve the `Docs/` directory with any static HTTP server. Navigation uses URL hashes, so no server-side routing is required.

The content is grounded in the `ui-rewrite` engine implementation. When adding or changing Lua bindings, components, editor workflows, or asset support, update `Docs/content.js` in the same change.
